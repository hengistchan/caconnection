## Quick Start

```bash
# Install dependencies
npm install

# Run tests
npm test

# Run in development mode
npm run dev

# Build for production
npm run build
npm start
```

## Testing

```bash
# Run all tests
npm test

# Run only compatibility tests
npm run test:compat

# Run tests in watch mode
npm run test:watch
```

### Golden Vector Tests

The `test/fixtures/golden-vectors.json` file contains test vectors generated by the Python gateway. These verify that Node.js produces byte-identical results for:

- HKDF key derivation
- AES-256-GCM encryption/decryption
- HMAC-SHA256 request signatures
- OTP candidate extraction

To regenerate golden vectors:
```bash
python3 server-node/scripts/generate-golden-vectors.py > server-node/test/fixtures/golden-vectors.json
```

## Architecture

```
src/
├── main.ts              # Entry point
├── app.ts               # Fastify application factory
├── config/
│   └── constants.ts     # All constants matching Python gateway
├── crypto/
│   ├── encoding.ts      # Base64 encode/decode
│   ├── payload-crypto.ts # AES-256-GCM encryption
│   ├── request-signature.ts # HMAC-SHA256 signatures
│   └── otp-extraction.ts # OTP candidate extraction
├── database/
│   └── database.ts      # SQLite connection and schema
└── ...
```

## Compatibility

This implementation maintains strict compatibility with the Python gateway:

1. **Crypto**: All encryption/decryption produces identical output
2. **Signatures**: HMAC verification is byte-compatible
3. **Database**: Same schema, same WAL mode, same pragmas
4. **API**: Same endpoints, same response formats
5. **OTP**: Same extraction logic and ranking

## Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `PORT` | `8787` | Server port |
| `HOST` | `0.0.0.0` | Server host |
| `DATABASE_PATH` | `./data/gateway.db` | SQLite database path |
| `TRUST_PROXY` | `false` | Trust X-Forwarded-For headers |
